# University PLC Automation Project

University project focused on the automation of a piece goods handling process using PLC technology.

## Project Overview

The project was developed as a team and focused on the automation and integration of a complete industrial process.

The overall system included:

- PLC control
- Digital twins
- WinCC visualization
- Node-RED integration
- Robot and RFID integration
- Testing and commissioning

## My Contribution

I was part of the **PLC team** and worked mainly on the control and automation logic.

My responsibilities included:

- Developing PLC control concepts
- Designing Petri nets for process sequences
- Implementing control logic for manual and automatic operation
- Defining PLC interfaces and data blocks
- Integrating different machine components
- Testing and debugging the control logic

The project included components such as the linear axis, gripper portal, robot, swivel arm and pusher.
